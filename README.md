Pharmacy Management System

Project Description

A Pharmacy Management System developed using Java and MySQL.
This system helps manage medicines, staff, purchases, and sales efficiently.


Technologies Used

- Java
- MySQL
- JDBC
- Eclipse IDE


Main Features

- Medicine Management
- Staff Management
- Medicine Information Management
- Database Connectivity
- User Login
- Purchase Management
- Sales Management
- Stock Management


Project Structure

src/
└── main/
    └── java/
        ├── controller/
        ├── dao/
        ├── model/
        ├── util/
        └── view/


Installation

1. Clone or download this repository.
2. Open the project in Eclipse IDE.
3. Configure the MySQL database connection.
4. Set up the required database and tables.
5. Run the application.
