Pharmacy Management System

A desktop-based Pharmacy Management System developed using Java and MySQL.

About the Project

This project was developed as part of an Object-Oriented Design and Development (OODD) project. It helps manage pharmacy operations and medicine information.

Technologies Used

- Java
- MySQL
- JDBC
- Eclipse IDE

Main Features

- Medicine Management
- Staff Management
- Medicine Information management
- Database Connectivity
- User Login

Project Structure
src/
└── main/
    └── java/
        ├── controller/
        ├── dao/
        ├── model/
        ├── util/
        └── view/
Installation

1. Clone or download this repository.
2. Open the project in Eclipse IDE.
3. Configure the MySQL database connection.
4. Set up the required database and tables.
5.Run the application.
